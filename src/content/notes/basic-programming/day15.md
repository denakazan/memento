## C言語の文字列

C言語には専用の文字列型がなく、文字列は `char` の配列として表現され、末尾に終端文字 `'\0'`(ヌル文字)を置くことで長さの範囲を示す。

```c
char s[6] = "Hello"; // 実際は 'H','e','l','l','o','\0' の6文字分
```

## string.h の代表的な関数

```c
#include <string.h>

strlen(s);        // 文字列の長さ(終端文字を含まない)
strcpy(dst, src);  // srcをdstにコピー
strcat(dst, src);  // dstの末尾にsrcを連結
strcmp(s1, s2);    // 文字列を比較(等しければ0)
```

配列としてメモリを扱う都合上、コピー先の配列の大きさが足りないと、メモリを壊してしまう(バッファオーバーフロー)ことがあるため、サイズの管理には注意が必要。
