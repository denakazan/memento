## 時間計算量

入力サイズ $n$ が大きくなったとき、処理時間がどのくらいの速さで増えるかを表す指標。$O(\cdot)$ という記法(オーダー記法)で表す。

- $O(1)$: 入力サイズによらず一定時間
- $O(n)$: 配列を1回走査するような処理
- $O(n^2)$: 選択ソート・バブルソートのような、二重ループを持つ処理
- $O(\log n)$: 二分探索のような、毎回範囲を半分にする処理

同じ問題でも、アルゴリズムによって計算量が大きく変わることがある。

## 乱数とランダム性

コンピュータが生成する乱数の多くは、計算式で作られる疑似乱数であり、種(シード)が同じなら同じ数列が再現される。

```java
Random rnd = new Random();
int dice = rnd.nextInt(6) + 1; // 1〜6の乱数
```

シードを固定すると、実行するたびに同じ乱数列が得られるため、デバッグやテストに便利。
