## 2次元配列

配列の配列として、表形式のデータを扱える。

```java
int[][] grid = new int[3][4]; // 3行4列
grid[1][2] = 5;

for (int i = 0; i < grid.length; i++) {
    for (int j = 0; j < grid[i].length; j++) {
        System.out.print(grid[i][j] + " ");
    }
    System.out.println();
}
```

## レコード

型の異なる複数のデータを、意味のあるまとまりとして1つにしたもの。

```java
class Point {
    int x;
    int y;
}
```

## 画像

画像は、各マスに色の情報(赤・緑・青の強さなど)を持つ、大きな2次元配列(ピクセルの格子)として表現できる。座標 $(i,j)$ の画素の色を `pixel[i][j]` のように参照する、というイメージ。
