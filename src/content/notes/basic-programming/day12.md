## 数値型のサイズ

```c
char   c; // 1バイト
short  s; // 2バイト
int    i; // 4バイト(処理系による)
long   l; // 4または8バイト
float  f; // 4バイト
double d; // 8バイト
```

型によって表現できる値の範囲や精度が異なる。

## 配列

```c
int a[5] = {1, 2, 3, 4, 5};
```

## ポインタ

変数のアドレス(メモリ上の位置)を格納する変数。

```c
int x = 10;
int *p = &x;   // xのアドレスをpに代入
printf("%d\n", *p); // pの指す先の値(=x)を表示
```

`&` はアドレスを取り出す演算子、`*` はポインタの指す先の値を取り出す演算子。C言語特有の重要な概念で、配列や関数への参照渡しの基礎になる。
