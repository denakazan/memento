## 手続き(メソッド)

まとまった処理に名前をつけて、何度でも呼び出せるようにしたもの。

```java
static int sum(int[] a) {
    int s = 0;
    for (int i = 0; i < a.length; i++) {
        s += a[i];
    }
    return s;
}
```

## 再帰

メソッドが自分自身を呼び出すこと。「基底となる小さいケース」と「それ以外を、より小さい問題に帰着させる部分」の2つで構成する。

```java
static int factorial(int n) {
    if (n == 0) {
        return 1; // 基底ケース
    }
    return n * factorial(n - 1); // n! = n * (n-1)!
}
```

再帰は、配列を先頭と残りに分けて考えるなど、配列を使ったアルゴリズムとも相性がよい。
