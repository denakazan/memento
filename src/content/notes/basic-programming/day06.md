これまで学んだ2次元配列・2重ループ・条件分岐を組み合わせ、実際に画像を生成する。

## 基本方針

すべてのピクセル $(i,j)$ について、座標をもとに色を計算して代入する、という2重ループを回す。

```java
int width = 256, height = 256;
int[][] image = new int[height][width];

for (int i = 0; i < height; i++) {
    for (int j = 0; j < width; j++) {
        // 横方向の位置に応じて明るさが変わるグラデーション
        image[i][j] = j; // 0(黒)〜255(白)
    }
}
```

## 応用例

- 座標からの距離を使って同心円状の模様を作る
- $i$、$j$ の偶奇を使って市松模様を作る
- 数式(三角関数など)を使って波状の模様を作る

「座標 → 色」という関数さえ決めれば、あとは全ピクセルに対して同じ計算を繰り返すだけで画像が作れる。
