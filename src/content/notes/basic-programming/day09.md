## クラスとオブジェクト

関連するデータ(フィールド)と、それを操作する処理(メソッド)をひとまとめにした設計図をクラスといい、クラスから実際に作られた実体をオブジェクト(インスタンス)という。

```java
class Circle {
    double radius;

    double area() {
        return Math.PI * radius * radius;
    }
}

Circle c = new Circle();
c.radius = 2.0;
System.out.println(c.area());
```

## オブジェクト指向の利点

- データと、それに関係する処理をまとめて管理できる
- 同じクラスから、異なるデータを持つオブジェクトをいくつでも作れる
- 内部の実装を隠しつつ、外部には必要な操作だけを公開できる(カプセル化)
