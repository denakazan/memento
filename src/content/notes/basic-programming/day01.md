## プログラミング入門

ソースコードを書き、コンパイル(または実行)して、コンピュータに処理を行わせる。プログラムは「順次(上から順に実行)」「分岐」「反復」という3つの基本構造の組み合わせでできている。

## さまざまな誤差

コンピュータは実数を有限桁の2進数(浮動小数点数)で近似して扱うため、次のような誤差が生じる。

- **丸め誤差**: 表現できない桁を四捨五入・切り捨てすることによる誤差
- **打ち切り誤差**: 無限級数などの計算を途中で打ち切ることによる誤差
- **桁落ち**: 近い値どうしを引き算したときに、有効桁数が大きく減ってしまう現象
- **情報落ち**: 絶対値の差が大きい値どうしを足し算したときに、小さい方の値が計算に反映されない現象
- **オーバーフロー/アンダーフロー**: 表現できる範囲を超えて大きい/小さい値になってしまう現象

```java
double a = 0.1 + 0.2;
System.out.println(a); // 0.3 にならず 0.30000000000000004 になる(丸め誤差の例)
```
