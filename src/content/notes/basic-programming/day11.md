## C言語の基本構造

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```

`main` 関数がプログラムの実行開始位置になる。

## 型と宣言

変数を使う前に、型を指定して宣言する必要がある。

```c
int i = 10;       // 整数
double x = 3.14;  // 浮動小数点数
char c = 'A';     // 1文字
```

Javaと違い、C言語では変数の型に合わせてメモリの使い方が明確に決まる。宣言と同時に初期化しない場合、変数の値は不定(ゴミ値)になる点に注意。
