## 制御構造の復習

プログラムは「順次」「分岐」「反復」の3つの基本構造の組み合わせで、どんな処理も表現できる(構造化定理)。

## 配列

同じ型の値を複数まとめて扱うためのデータ構造。

```java
int[] scores = new int[5];
scores[0] = 80;
scores[1] = 95;

for (int i = 0; i < scores.length; i++) {
    System.out.println(scores[i]);
}
```

添字(インデックス)は0から始まる。範囲外の添字にアクセスすると実行時エラーになる。

## 配列を使う典型例

- 合計・平均を求める(すべての要素を足し合わせる)
- 最大値・最小値を求める(先頭を仮の最大値とし、順に比較して更新する)
- 探索(目的の値が配列に含まれるか調べる)
