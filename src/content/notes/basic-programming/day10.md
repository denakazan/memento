## 動的データ構造

配列はサイズが固定だが、連結リストのように、実行中に要素を追加・削除できるデータ構造もある。各要素(ノード)が、次の要素への参照を持つことでつながっている。

```java
class Node {
    int value;
    Node next;
}
```

先頭のノードから `next` をたどっていくことで、リスト全体を走査できる。

## 情報隠蔽(カプセル化)

クラスの内部のデータ(フィールド)を直接いじれないようにし、決められたメソッド経由でだけアクセスさせる考え方。

```java
class Counter {
    private int count = 0; // 外部から直接は触れない

    void increment() {
        count++;
    }

    int get() {
        return count;
    }
}
```

内部の実装を自由に変更できるようになり、外部のコードへの影響を防げる。
